# Atribusi model

Model perabot di folder ini dipakai bersama oleh semua site (`model://<Nama>`). Sebagian besar berasal dari [Gazebo Fuel](https://app.gazebosim.org/fuel/models) milik OpenRobotics. Model berlisensi CC-BY 4.0 wajib dicantumkan atribusinya setiap kali model didistribusikan, termasuk lewat repo ini dan paket rilis.

Bangunan site (`sites/<site>/models/<site>`) dibuat oleh ORBIT Team.
